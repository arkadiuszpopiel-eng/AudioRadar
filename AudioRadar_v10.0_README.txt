  🎯 PIERWSZE URUCHOMIENIE
═══════════════════════════════════════════════════════════════════════════

Po uruchomieniu START_HERE.bat:

1. Wybierz urządzenie:
   - Znajdź urządzenie z [LOOPBACK] (np. Stereo Mix)
   - Ustaw częstotliwość: 48000 Hz
   - Ustaw bufor: 128 ramek

2. Naciśnij SPACJA lub START

3. Sprawdź status:
   - LED: 🟢 Połączono (zielony = OK)
   - Opóźnienie: ~10ms
   - CPU: 3-5%

═══════════════════════════════════════════════════════════════════════════
  ⚠️ ROZWIĄZYWANIE PROBLEMÓW
═══════════════════════════════════════════════════════════════════════════

PROBLEM: START_HERE.bat nie działa
ROZWIĄZANIE:
1. Zainstaluj Python 3.11+ z python.org
2. Podczas instalacji zaznacz "Add Python to PATH"
3. Uruchom ponownie START_HERE.bat

PROBLEM: Brak urządzeń loopback
ROZWIĄZANIE:
1. Panel sterowania → Dźwięk → Nagrywanie
2. PPM → Pokaż wyłączone urządzenia
3. Włącz "Stereo Mix" lub "What U Hear"

PROBLEM: Błąd importu PyQt5
ROZWIĄZANIE:
1. Otwórz wiersz poleceń w folderze audio_radar
2. Wykonaj: pip install -r requirements.txt

Więcej w: audio_radar/README_PL.txt

INSTALLATION
------------
1. Extract AudioRadar_v10_1_FULL.zip to your desired location
2. Run QUICKSTART.cmd (Windows) or follow INSTALL.md
3. Use calibrate.py to tune detection thresholds for your games
4. Read USER_GUIDE.md for tips and configuration examples

QUICK START
-----------
Windows:
  1. Double-click QUICKSTART.cmd
  2. Follow on-screen instructions

Manual:
  1. Install Python 3.8+
  2. Run: pip install -r requirements.txt
  3. cd audio_radar
  4. Run: python main.py

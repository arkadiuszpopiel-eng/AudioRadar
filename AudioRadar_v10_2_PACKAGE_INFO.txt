INSTALLATION
------------
1. Extract AudioRadar_v10_2_FULL.zip to your desired location

2. Windows Quick Start:
   - Double-click QUICKSTART.cmd
   - Follow on-screen instructions

3. Manual Installation:
   pip install -r requirements.txt
   cd audio_radar_v10/audio_radar
   python main.py

4. If pygame installation fails (Python 3.14):
   pip install -r requirements-windows.txt
   (Or install Python 3.11/3.12 - recommended)

IMPORTANT: AUDIO CONFIGURATION
------------------------------
⚠️ AudioRadar requires audio loopback to detect game sounds!

Windows Setup:
1. Open Settings → Sound → Recording (or right-click sound icon)
2. Right-click in recording devices → "Show Disabled Devices"
3. Find "Stereo Mix" → Right-click → Enable
4. Right-click "Stereo Mix" → "Set as Default Device"
5. Restart AudioRadar

Without Stereo Mix enabled:
- calibrate.py will close immediately with error
- main.py won't detect any sounds
- No bars will light up on the radar

USAGE
-----
1. Start AudioRadar:
   cd audio_radar_v10/audio_radar
   python main.py

2. Calibrate thresholds (optional but recommended):
   python calibrate.py
   - Watch Peak/RMS values while playing game sounds
   - Press 'y' to update config.json with recommended values

3. Controls while running:
   Z/X - Adjust bar width
   C/V - Adjust bar height  
   B/N - Adjust transparency
   ESC - Exit

4. What you'll see:
   - Czarne okno 600x600 px (black window)
   - 8 szarych konturów (8 gray bar outlines)
   - ZIELONE paski = footsteps (kroki)
   - CZERWONE paski = gunshots (strzały)

TROUBLESHOOTING
---------------
Problem: calibrate.py closes immediately
Solution: Check if Stereo Mix is enabled and set as default recording device
         Run: python main.py --list-devices
         Should see "Stereo Mix" in the list

Problem: No bars light up / detection doesn't work
Solution: 1. Verify Stereo Mix is enabled
         2. Play loud game sounds/music
         3. Run calibrate.py - you should see Peak/RMS values changing
         4. If values don't change, Stereo Mix isn't capturing audio

Problem: pygame won't install (Python 3.14)
Solution: Use Python 3.11 or 3.12 (recommended)
         OR: pip install -r requirements-windows.txt
         OR: pip install pygame==2.5.2 --only-binary :all:

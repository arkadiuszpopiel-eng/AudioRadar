═══════════════════════════════════════════════════════════════
💻 MANUAL INSTALLATION
═══════════════════════════════════════════════════════════════

STEP 1: Install Dependencies
────────────────────────────
cd AudioRadar_v10_3_package
pip install -r requirements.txt

# If pygame fails (Python 3.14):
pip install -r requirements-windows.txt

STEP 2: Run AudioRadar
───────────────────────
cd audio_radar_v10/audio_radar
python main.py

STEP 3: Enjoy!
──────────────
✓ Stats overlay shows Peak/RMS in top-left
✓ Auto-detects Stereo Mix
✓ Green bars = footsteps, Red bars = shots
✓ Use Z/X/C/V/B/N keys to adjust display

🔧 SYSTEM REQUIREMENTS
═══════════════════════════════════════════════════════════════

✓ Python 3.11 or 3.12 (recommended)
✓ Python 3.14 supported with requirements-windows.txt
✓ Windows 10/11 (Stereo Mix required for detection)
✓ 50 MB disk space
✓ Audio loopback device (Stereo Mix)

═══════════════════════════════════════════════════════════════
🎮 ENABLING STEREO MIX (IF NEEDED)
═══════════════════════════════════════════════════════════════

If auto-detection fails, manually enable:

1. Windows Settings → Sound → Recording
2. Right-click → "Show Disabled Devices"
3. Right-click "Stereo Mix" → Enable
4. Right-click "Stereo Mix" → Set as Default Device
5. Restart AudioRadar

v10.3 will detect it automatically on next run!

═══════════════════════════════════════════════════════════════
🐛 TROUBLESHOOTING v10.3
═══════════════════════════════════════════════════════════════

PROBLEM: "No audio device detected"
SOLUTION: Run calibrate.py to see error details
          Enable Stereo Mix in Windows Sound settings

PROBLEM: Stats show 0.000 values
SOLUTION: Audio not playing or Stereo Mix not default
          Play music and check stats overlay updates

PROBLEM: pygame installation fails
SOLUTION: Use requirements-windows.txt
          Or install Python 3.11/3.12 instead

PROBLEM: Stats overlay too bright/dim
SOLUTION: Background opacity is fixed at 180/255
          Future v11 will have adjustable overlay

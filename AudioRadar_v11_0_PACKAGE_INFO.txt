🚀 QUICK START GUIDE

WINDOWS USERS (Recommended):
  1. Extract AudioRadar_v11_0_FULL.zip to desired location
  2. Double-click QUICKSTART_v11.cmd
  3. Follow on-screen instructions
  4. GUI opens automatically!

MANUAL INSTALLATION (All platforms):
  1. Extract AudioRadar_v11_0_FULL.zip
  2. Open terminal/command prompt
  3. Run: pip install -r requirements.txt
  4. Navigate to: cd audio_radar_v11
  5. Run: python -m audio_radar
  6. Modern GUI launches!

🎮 USAGE GUIDE

FIRST TIME SETUP:

  1. Enable Stereo Mix (Windows):
     • Right-click speaker icon in taskbar
     • Select "Sounds" → "Recording" tab
     • Right-click empty space → "Show Disabled Devices"
     • Right-click "Stereo Mix" → Enable
     • Right-click "Stereo Mix" → "Set as Default Device"

  2. Launch AudioRadar v11:
     • Run QUICKSTART_v11.cmd or python -m audio_radar
     • GUI window opens with control panel

  3. Configure Detection:
     • Adjust Volume Threshold slider (start with 0.3)
     • Set Sensitivity (start with 0.5)
     • Enable Filter for better accuracy
     • Click "Start Detection"

  4. Test Detection:
     • Play game or audio
     • Watch stats update in real-time
     • Adjust threshold/sensitivity as needed

CONTROL PANEL:

  Volume Threshold:
    Controls minimum volume level for detection
    Lower = more sensitive, Higher = less sensitive
    Recommended: 0.2-0.4 for gaming

  Sensitivity:
    Fine-tunes detection responsiveness
    Lower = fewer false positives
    Higher = more detections
    Recommended: 0.4-0.6

  Enable Filter:
    Applies bandpass filtering for better accuracy
    Recommended: Enabled for gaming

  Auto-Calibration:
    Automatically adjusts thresholds based on audio
    Experimental feature
    Recommended: Disabled initially

KEYBOARD SHORTCUTS:

  During Detection:
    • Space - Pause/Resume detection
    • C - Run calibration routine
    • R - Reset to default settings
    • S - Save current configuration
    • B - Toggle borderless window mode
    • T - Toggle always-on-top mode
    • + - Increase window opacity
    • - - Decrease window opacity
    • Esc - Exit application

🔧 TROUBLESHOOTING

ISSUE: "No audio device found" error
  SOLUTION:
    • Ensure Stereo Mix is enabled and set as default
    • Check Windows Sound settings
    • Restart AudioRadar after configuring Stereo Mix
    • Try running as Administrator

ISSUE: Detection not working / No bars appearing
  SOLUTION:
    • Verify Stereo Mix is capturing audio (test in Windows settings)
    • Increase Volume Threshold (try 0.5-0.7)
    • Disable other audio recording apps
    • Check audioradar_v11.log for errors
    • Ensure game audio is playing through speakers (not headphones only)

ISSUE: Too many false detections
  SOLUTION:
    • Lower Sensitivity slider
    • Increase Volume Threshold
    • Enable Filter if not already enabled
    • Run calibration (press C) with game audio playing

ISSUE: GUI window not appearing
  SOLUTION:
    • Check if window is behind other windows
    • Try Alt+Tab to find it
    • Check audioradar_v11.log for errors
    • Ensure tkinter is installed (should come with Python)

ISSUE: "Module not found" errors
  SOLUTION:
    • Run: pip install -r requirements.txt
    • Use Python 3.11 or 3.12
    • Try: pip install --upgrade pip
    • Install packages individually if batch fails

ISSUE: Window too transparent / can't see controls
  SOLUTION:
    • Press + key multiple times to increase opacity
    • Edit config_v11.json and set "opacity": 100
    • Restart application

🎯 TIPS FOR BEST RESULTS

  1. Calibration:
     • Start game and play normally
     • Press C to run calibration
     • Let it run for 30-60 seconds
     • Adjust thresholds based on results

  2. Threshold Tuning:
     • Start with Volume Threshold = 0.3
     • If too sensitive: increase to 0.4-0.5
     • If missing detections: decrease to 0.2-0.25
     • Watch Peak values in stats to guide adjustment

  3. Sensitivity Tuning:
     • Start with Sensitivity = 0.5
     • For precise detection: decrease to 0.3-0.4
     • For maximum detection: increase to 0.6-0.7
     • Balance between false positives and missed events

  4. Filter Usage:
     • Always enable for gaming
     • Reduces background noise
     • Improves directional accuracy

  5. Window Positioning:
     • Drag window to preferred location
     • Click "Save Config" to remember position
     • Use borderless mode for cleaner look
     • Toggle always-on-top to keep visible

🎊 UPGRADE FROM v10.3

If you're upgrading from v10.3:

  1. Keep v10.3 folder (for backup)
  2. Extract v11.0 to new folder
  3. Install dependencies: pip install -r requirements.txt
  4. Run v11.0: python -m audio_radar
  5. Configure settings in GUI (no need to edit files!)
  6. Your v10.3 settings won't transfer (different config format)

Both versions can coexist - they use different folders and configs.

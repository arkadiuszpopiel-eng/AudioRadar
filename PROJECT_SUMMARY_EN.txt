## 3. RECENT FIXES (k0019-k0022)

✓ k0019 - ML Training DEADLOCK Fix
-----------------------------------
Problem: Start button in ML Training froze entire program
Root Cause: threading.Lock() not reentrant - same thread tried to acquire
            lock twice
Solution: Changed to threading.RLock() (reentrant lock)
Files: app/ml/training/recorder.py:90

Root Cause: Synchronous callback executed before assignment completed
Solution: Safe session_id access with try-except in callback
Files: app/ml/training/recorder.py:205-211

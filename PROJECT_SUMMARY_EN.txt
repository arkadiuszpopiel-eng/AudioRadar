PROBLEM 3: UI Turning White After Tab Switches (entire program breaks!)
------------------------------------------------------------------------
Report: "After several tab changes entire program breaks UI becomes white!"

Root cause:
- Global stylesheet lacked specific rules for QTabWidget, QStackedWidget, tables
- During tab switches, Qt reset widget backgrounds to system defaults
- Widgets without explicit styles fell back to QPalette defaults = white backgrounds
- Stylesheet inheritance broke during dynamic widget creation

Solution - Enhanced Global Stylesheet (main.py lines 291-333):

1. Added explicit QTabWidget rules:
   - QTabWidget { background-color: #191923; }
   - QTabWidget::pane { background-color: #191923; border: 1px solid #2A82DA; }
   - Prevents white backgrounds in tab content areas

2. Added comprehensive QTabBar rules:
   - QTabBar { background-color: #191923; }
   - QTabBar::tab { background: #2D2D37; color: #DCDCE6; }
   - QTabBar::tab:selected { background: #2A82DA; color: white; }
   - QTabBar::tab:hover { background: #3D3D47; }
   - Ensures tabs always maintain dark theme

3. Added global QTableWidget defaults:
   - Background: #1a1a1a
   - Text: #DCDCE6
   - Item backgrounds: #1a1a1a
   - Selection: #2A82DA
   - Headers: #2D2D37 with #DCDCE6 text
   - Fallback for tables without explicit styles

4. Added QStackedWidget rules:
   - Background: #191923
   - Ensures stacked widget containers stay dark

5. Enhanced QHeaderView rules:
   - Consistent header colors across all tables
   - Prevents white headers

Technical details:
Bug occurred because:
- Qt stylesheet inheritance can break during dynamic widget creation
- Tab switches may recreate widgets or reset their style contexts
- Widgets without explicit styles fall back to QPalette/system defaults
- System palette can override application palette in certain situations

Fix ensures:
- Every widget type has explicit dark theme rules
- TabWidget and its children maintain styling during switches
- Tables always get dark backgrounds as fallback
- Stacked widgets (used for tab content) stay dark
- No opportunity for system defaults to leak through

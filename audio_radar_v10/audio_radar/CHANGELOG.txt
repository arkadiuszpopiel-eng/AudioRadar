────────────────────────────────────────────────────────────────────────────
⚡ OPTIMIZED (Optymalizacje)
────────────────────────────────────────────────────────────────────────────

[Audio Processing]
* Bufor 128 zamiast 256 ramek:
  - Opóźnienie: ~10ms @ 48kHz (było ~20ms)
  - Poprawa responsywności o 50%
  
* Priorytet wątku TIME_CRITICAL (15) dla audio:
  - Zmniejszenie jittera
  - Lepsza stabilność przy obciążeniu systemu
  - Wykorzystanie Windows Thread Priority API
  
* Optymalizacja LevelBuffer.pop_latest():
  - Bezpośredni dostęp do najnowszej wartości
  - Pominięcie starych próbek
  - Redukcja opóźnienia procesowania

[GUI Rendering]
* Timer 16ms zamiast 50ms:
  - 60 FPS zamiast 20 FPS
  - Płynniejsza animacja wskaźników
  - Lepsza responsywność interfejsu
  
* Efektywne odświeżanie tylko zmienionych kontrolek
* Optymalne rozmiary buforów i kolejek

[Memory Management]
* Deque zamiast list dla historii opóźnień
* Automatyczne ograniczenie rozmiaru historii (maxlen)
* Graceful cleanup przy zamykaniu

🔄 MIGRATION GUIDE (Migracja z v9.9.32)
────────────────────────────────────────────────────────────────────────────

WYMAGANE KROKI:

1. Instalacja nowych zależności:
   pip install PyQt5 pyaudiowpatch psutil

2. Sprawdzenie compatibility:
   - Stare pliki config.json będą działać
   - Logi teraz w log_v10.txt (zamiast log_v9.txt)
   - Pygame nadal dostępne jako fallback

3. Konfiguracja urządzeń:
   - Urządzenia loopback teraz wyraźnie oznaczone
   - Może być potrzeba ponownego wyboru urządzenia
   - Zalecane: 128 ramek bufora (było 256)

4. Nowe funkcje:
   - Używaj SPACJA do START/STOP
   - Używaj F5 do odświeżenia urządzeń
   - Monitoruj opóźnienie i CPU w statusie

KOMPATYBILNOŚĆ WSTECZNA:

✓ Stare config.json działają bez zmian
✓ Pygame fallback jeśli PyQt5 niedostępny
✓ Wszystkie stare parametry audio obsługiwane
✓ Logi zachowują kompatybilny format

BREAKING CHANGES:

✗ Nowy main entry point w __main__.py (API wewnętrzne)
✗ Struktura modułów zmieniona (dodano 3 nowe pliki)
✗ GUI framework zmieniony z pygame na PyQt5

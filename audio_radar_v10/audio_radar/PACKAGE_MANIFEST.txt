═══════════════════════════════════════════════════════════════════════

REQUIREMENTS
═══════════════════════════════════════════════════════════════════════

Python 3.8+ with the following packages:
• PyQt5 (GUI framework)
• sounddevice (audio capture)
• numpy (signal processing)
• psutil (performance monitoring)
• scipy (optional, advanced analysis)

All dependencies are automatically installed by START_V10_GUI.bat

BUILDING STANDALONE EXECUTABLE
═══════════════════════════════════════════════════════════════════════

To create a standalone .exe file:

1. Open Command Prompt in the package folder
2. Run: RUN_BUILD_ALL.cmd build
3. Find the executable in: dist\AudioRadar_v10_GUI.exe

The executable includes all dependencies and can be distributed without
requiring Python installation.

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

If you see a black Pygame screen:
  1. Close the application
  2. Delete __pycache__ folder
  3. Run: pip install --upgrade PyQt5
  4. Restart with START_V10_GUI.bat

If dependencies fail to install:
  1. Manually install: pip install PyQt5 sounddevice numpy psutil
  2. Run: python main.py

For detailed troubleshooting, see README_PL.txt section:
"ROZWIĄZYWANIE PROBLEMÓW - GUI"
